# ファイル操作の安全規則

- **文字コードと改行コードを確かめる**: Write / Edit で書いたファイルは、フック `post-edit-check.py` が `check-encoding.py` の規則で自動検査する（ERROR は差し戻し、WARN は注意として届く）。フックを通らないファイル（Bash でコピー・生成・変換したもの、よそから持ち込んだもの）と、自分が書いていない `.ps1` / `.sh` を実行する前は、`python ~/.claude/scripts/check-encoding.py <パス...>` で検査する（ERROR なら終了コード 1。`--fix` で BOM・改行を修正できる）。この種の不一致は書いた直後には表に出ず、実行・解析して初めて壊れる。形式ごとの要件と根拠は同スクリプトの `RULES`
- **編集後に 0 バイトになっていないか確かめる**: 0 バイトになっていたら、すぐ作業を止めてユーザーに報告する
- **ユーザーが自分でやると言った操作はしない**: 「私が行います」「自分でやります」と返されたら、その操作は実行しない
